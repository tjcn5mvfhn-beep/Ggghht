# MineSlot Landing

Готовый Next.js + TypeScript + Tailwind проект для Vercel.

Локальный запуск:
npm install
npm run dev

Деплой: загрузите содержимое этой папки в корень GitHub-репозитория и импортируйте репозиторий в Vercel.

Перед публикацией замените демонстрационные тексты, изображения, ссылки и рекламные условия на собственные и проверьте применимые требования.
